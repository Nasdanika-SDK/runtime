The supertype is set on line 5, recorded there, and resolved after the script, under "Resolving references", with the line it was written on.

[cols="2,4",options="header"]
|===
| Span | Attributes
| `Compiling script` | The URI; the line of a syntax error
| `Evaluating script` | The URI and the number of roots; the line of a failure
| `Loading <Type>` | `nasdanika.dsl.type`, the type as `<nsURI>#<name>`; `nasdanika.dsl.type.superseded` when it superseded less specific types; the line; `nasdanika.dsl.prototype.uri` for a copy
| `Setting <feature>` | `nasdanika.dsl.feature`, `nasdanika.dsl.feature.class`, `nasdanika.dsl.feature.kind` (`attribute`, `containment` or `reference`), the line; `nasdanika.dsl.deferred` when resolved after the script
| `Resolving references` | `nasdanika.dsl.references`, the number of deferred references
| `Resolving <feature>` | The feature's attributes, and the line the reference was written on
| `Loading resource` | `nasdanika.dsl.target.uri`, for `loadResource`
|===

`global` emits a log record, `nasdanika.dsl.global`, with the URI, the type and the line.
Resolving the capabilities that compile and evaluate the script is traced too, before "Compiling script".

The spans carry locations and types, never values: a model may hold data that a trace must not.
