== About the author

image::headshot.jpg[Pavel Vlasov,width=178,pdfwidth=35%,align=center]

I am Pavel Vlasov, the creator of Nasdanika and of the runtime this book describes.
I have worked in information technology for more than thirty years, thirty of them in financial services, as a developer, an architect and an enterprise architect.

I hold a master's degree in plasma physics.
I am certified as a Java developer and as a Java architect, as a TOGAF Enterprise Architecture Practitioner, and as a Project Management Professional.

I write about models, architecture and AI-assisted development at {medium}.
