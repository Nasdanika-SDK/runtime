== Preface

This book is about running code against an HTTP server and keeping a record of what both sides did.
It describes `harness`, a small module of the Nasdanika SDK Runtime with one method at its heart: `Harness.inServer`, which starts a server, runs your code while the server is up, and stops it.
Everything that happens in between, the requests your code sends and the work the server does to answer them, is one OpenTelemetry trace, and with the runtime's telemetry model the trace is saved as a model you can query, compare and generate documents from.

The first part is the why: why tests should leave a trace, and why the module is as small as it is.
The second part is the how.
The third says what is built on it and what comes next.

=== Who this book is for

*Java developers who test web applications and services*, and want a failed test to say what the server did, not only what the client got.

*Developers who build demos and walk-throughs* of web applications, and want them reproducible and documented by the same run.

*Architects* who want end-to-end traceability from a requirement, through a test, to the code that served it. Part one is for you, and needs no code.

=== A book that stands on its own

This book is one of the Nasdanika Zephyr Books: in-depth manuals, one per module of the Nasdanika SDK Runtime, in the manner of IBM Redbooks.
The runtime has a book of its own, _Nasdanika SDK Runtime: More Structure with Less Effort_, and the browser side of the same idea has a Zephyr Book, _Walk-throughs with Playwright_.
You do not need either to read this one: where the books touch, this one repeats what you need.

The series is named after the Bootswatch theme it is styled with, Zephyr, and has nothing to do with the Zephyr real-time operating system or with SmartBear's Zephyr test management.

=== What you need

* *A JDK for Java 25* and *Maven 3.9.16 or later*.
* The module is `org.nasdanika.sdk.runtime.harness`, Maven coordinates `{group-id}:{artifact-id}:{runtime-version}`.
* To record telemetry as models, the runtime's telemetry model exporters, `org.nasdanika.sdk.runtime.models.telemetry:exporters`, which bring the OpenTelemetry SDK.

=== Conventions

* *Every listing is included from the module's sources or tests* and compiled and run when the book is built. Callouts, such as <1>, explain the lines they mark.
* *Status labels* mark what this edition does not have yet: [.planned]#PLANNED# for designed but not built.
* *Voice.* I write in the first person.
