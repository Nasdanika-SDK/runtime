== Building this book

This book is AsciiDoc in `playwright/src/docs/asciidoc`, built with the module after its tests have passed:

[source,text]
----
mvn -pl playwright verify                                # the module, its tests and this book
mvn -pl playwright verify -Dplaywright.channel=msedge    # tests with Microsoft Edge
mvn -pl playwright verify -Dplaywright.channel=          # tests with Playwright's Chromium
mvn -pl playwright verify -Dzephyr.editor-notes=false    # without editor's notes
mvn -pl playwright verify -Dasciidoctor.skip=true        # without the book
----

The PDF, the single-page HTML and the EPUB are written to `target/book`; the PDF and the HTML are attached to the module's artifact with the classifier `book`, and the test sources with the classifier `test-sources`.
The look comes from the runtime's `doc/zephyr` directory, shared by all the Nasdanika Zephyr Books.

Listings are tagged regions of the tests in `src/test/java/org/nasdanika/sdk/runtime/playwright/tests`, of the catalog application in `src/test/resources/catalog`, of the module's `module-info.java`, and of the React model's walk-through test.
The tests record their walk-throughs, with screenshots, in `target/walkthrough`, `target/failing-step` and `target/origins`.
The figures are copies of screenshots from those runs, in `src/test/resources/figures`, so that the book builds when the tests are skipped.
A listing line holds at most 96 characters, and a warning fails the build.
