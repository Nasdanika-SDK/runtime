=== A walk-through

`Browsing.inBrowser` runs a browser session against a harness server:

.Three steps through the catalog (`WalkthroughTests.java`)
[source,java]
----
include::{booktests}/WalkthroughTests.java[tag=walkthrough,indent=0]
----
<1> The recording: the trace, and the screenshots next to it, in `target/walkthrough`.
<2> A session against the server: a browser, a context whose relative URLs resolve against the server's base, and a page, in a `Browser` span.
<3> A relative URL: the server's page.
<4> Playwright's assertions wait for the page: the list has one item once the server has answered the search.

Each step is a span named after it, and narrated: the second argument is what a person would say about the step, recorded as it starts (<<narration>>).
With the default options, a step takes a screenshot before its body runs and another after, except before the first page is loaded, when there is nothing to see.

.After the second step (`003-search-for-dune-after.png`)

A step's body ends when its last Playwright call returns.
Waiting for what the step does, with an assertion or `waitFor`, inside the step, keeps the step's requests in the step: a request the page sends after the step ended belongs to whatever is current then.

=== Options

`Options` is a record with a `with` method per component, and `Options.DEFAULT`:

[cols="2,2,4",options="header"]
|===
| Component | Default | Meaning
| `channel` | none | An installed browser, such as `chrome` or `msedge`; none for Playwright's Chromium
| `headless` | `true` | Without a window
| `width`, `height` | 1280, 800 | The viewport, in CSS pixels
| `screenshots` | `target/screenshots` | The directory screenshots are written to, created if missing
| `stepScreenshots` | `BEFORE_AND_AFTER` | What a step takes by itself: `NONE`, `AFTER`, or `BEFORE_AND_AFTER`
| `fullPage` | `false` | The full scrollable page rather than the viewport
|===

Screenshots are named by their position in the session, the name of the step or screenshot, and the phase: `003-search-for-dune-after.png`.
Writing them to the recording's directory keeps the trace and its pictures together, and their paths, relative to the directory, valid wherever the directory is copied.

=== The session

The body receives a `Session`:

[cols="2,5",options="header"]
|===
| Method | Returns or does
| `page()` | The page, Playwright's `Page`
| `context()`, `browser()`, `playwright()` | The rest of Playwright
| `server()` | The harness server
| `options()` | The options
| `step(name, body)` | Runs the body in a span, with screenshots
| `step(name, narration, body)` | The same, narrated as it starts: after the "before" screenshot
| `narrate(text)`, `narrate(narration)` | Records a line of narration in the current span (<<narration>>)
| `screenshot(name)` | Takes a screenshot now, in the current span, and returns the file
|===
