== Overriding

Two modules may contribute a command with the same name under the same parent: a better `print`, a `save` that knows a corporate repository.
Picocli refuses two sub-commands with one name, so the runtime keeps one when it can tell which overrides the other, the way a subclass overrides a method.

=== The rules

Of commands with the same name under the same parent, a command overrides another when:

* its class is annotated with `@Overrides`, and the other is an instance of one of the listed types;
* it implements `Overrider`, and `overrides(other)` returns true;
* its class is a subclass of the other's class.

Commands that do not override each other are all kept, and picocli reports the duplicate name.
The same rules apply to mix-ins with the same name.

Overriding is what makes a command line polymorphic: a distribution for one audience adds a module whose commands replace the defaults, and nothing else changes.
