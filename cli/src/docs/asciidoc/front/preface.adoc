== Preface

This book is about command lines that assemble themselves.
It describes `cli`, the module of the Nasdanika SDK Runtime that builds a picocli command tree from whatever modules are on the module path: each module contributes commands and mix-ins, and each command says, with generic types, what it needs from its parent and what it accepts as sub-commands.
Nothing lists all the commands; the tree is what the modules contribute, and a command appears exactly where its declared needs are met.

The first part is the why: why a platform's command line should assemble itself, what picocli does so well that the runtime builds on it rather than beside it, and what Nasdanika adds.
The second part is the how.
The third is about the pipelines the approach makes possible.

=== Who this book is for

*Java developers who build command line tools* that grow by modules: a core, and features, formats and integrations that come and go with the dependencies.

*Developers of the runtime's modules and of modules built on it*, who contribute commands to `nsdk`, the runtime's command line, or to a command line of their own.

*Architects* who want a command line as the first user interface of a platform, for people, for build pipelines and for AI agents, with every run recorded as telemetry. Part one is for you, and needs no code.

=== A book that stands on its own

This book is one of the Nasdanika Zephyr Books: in-depth manuals, one per module of the Nasdanika SDK Runtime, in the manner of IBM Redbooks.
The runtime's own book, _Nasdanika SDK Runtime: More Structure with Less Effort_, introduces the command line in three chapters, and the runtime's `common` module, on which the wiring is built, has a Zephyr Book of its own, _Matching and Wiring_.
You do not need either to read this one: where the books touch, this one repeats what you need.

The series is named after the Bootswatch theme it is styled with, Zephyr, and has nothing to do with the Zephyr real-time operating system or with SmartBear's Zephyr test management.

=== What you need

* *A JDK for Java 25* and *Maven 3.9.16 or later*.
* The module is `org.nasdanika.sdk.runtime.cli`, Maven coordinates `{group-id}:{artifact-id}:{runtime-version}`.
* Some familiarity with picocli helps: its annotations are how commands are written. Its documentation, https://picocli.info, is excellent.

=== Conventions

* *Every listing is included from the module's sources or tests* and compiled and run when the book is built. Callouts, such as <1>, explain the lines they mark.
* *Status labels* mark what this edition does not have yet: [.planned]#PLANNED# for designed but not built, [.sketch]#SKETCH# for partly built.
* *Voice.* I write in the first person.
