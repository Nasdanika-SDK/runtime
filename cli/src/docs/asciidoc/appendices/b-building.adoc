== Building this book

This book is AsciiDoc in `cli/src/docs/asciidoc`, built with the module after its tests have passed:

[source,text]
----
mvn -pl cli verify                                # the module, its tests and this book
mvn -pl cli verify -Dzephyr.editor-notes=false    # without editor's notes
mvn -pl cli verify -Dasciidoctor.skip=true        # without the book
----

The PDF, the single-page HTML and the EPUB are written to `target/book`; the PDF and the HTML are attached to the module's artifact with the classifier `book`, and the test sources with the classifier `test-sources`.
The look comes from the runtime's `doc/zephyr` directory, shared by all the Nasdanika Zephyr Books.

Listings are tagged regions of the tests in `src/test/java/org/nasdanika/sdk/runtime/cli`, `PipelineTests`, `WiringTests`, `ContributionTests` and `LifecycleTests`, and of the module's `module-info.java` and `SaveModelCommand.java`.
The tests are in the module's own package because it is open: picocli and the wiring reach private members of commands, and a test package would have to be opened to them as well.
A listing line holds at most 96 characters, and a warning fails the build.
