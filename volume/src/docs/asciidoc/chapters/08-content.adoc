[#content]
== Content

`Content` has one abstract method, `openStream()`, so a lambda is a content, as the glossary's missing files are.
Its default methods give the rest: `writeTo(out)`, which pulls and copies unless the content can push; `length()` and `hash()`, empty unless known; `repeatable()`; and `publisher()`, a `Flow.Publisher` of byte buffers for the JDK HTTP client's `BodyPublishers.fromPublisher`.

=== Factories

[cols="2,5",options="header"]
|===
| Factory | Content
| `Content.of(bytes)` | In memory, copied, with a known length
| `Content.of(text, charset)` | Text, encoded when read
| `Content.of(supplier)` | From a stream supplier, called on every open
| `Content.of(uri)` | At a URI, requested on every open: HTTP and HTTPS through the JDK HTTP client, other schemes through `URL`. A 404 is a `NoSuchFileException`
| `Content.once(stream)` | A stream someone handed over. Not repeatable
| `Content.ofWriter(writer)` | Produced by a closure that writes to an output stream, when the content is read
| `Content.empty()` | No bytes
|===

=== Content produced by a writer

`Content.ofWriter` turns a closure that writes to an output stream into content without running it:

* `writeTo(out)` runs the writer on the consumer's stream, with no pipe and no thread.
* `openStream()` returns a lazy pipe. The writer starts on a virtual thread at the first read, and writes bounded chunks into a queue that the reader drains. A failure of the writer is rethrown to the reader, and a reader that closes early cancels the writer.
* Each read runs the writer again, so the content is repeatable as long as the writer is. `ofWriter(writer, false)` declares a writer that is not.
