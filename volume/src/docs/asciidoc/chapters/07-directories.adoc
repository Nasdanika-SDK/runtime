== Directories and adapters

=== A volume over a directory

`Volume.of(path)` is a writable volume over a directory of any NIO file system: the default one, a zip file system, an in-memory one.

* It validates paths, so that they cannot escape the root.
* It probes the file system for case sensitivity, instead of guessing it from the operating system.
* It keeps the semantics of a file system: writing into a missing directory fails, and so does deleting a directory that is not empty.

=== Adapters

`adapt(readMapper, writeMapper)` turns a volume of one kind of content into a volume of another.
It is how the runtime's TypeScript generator writes text, without converting it to bytes itself:

.A text volume over a directory (`VolumeBookTests.java`)
[source,java]
----
include::{booktests}/VolumeBookTests.java[tag=text-volume,indent=0]
----
<1> Reading maps bytes to text. The mapping runs when content is asked for, so a text volume reads eagerly.
<2> Writing maps text to bytes, encoded when the target volume reads the content.

`Volume.of(genericVolume)` goes the other way, and views a `GenericVolume<Content>` as a `Volume`.
