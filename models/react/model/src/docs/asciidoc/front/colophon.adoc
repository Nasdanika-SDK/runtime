== Colophon

*TypeScript and React Models: A Nasdanika Zephyr Book*

Edition {revnumber}, built on {revdate}.

This edition describes four models of the Nasdanika SDK Runtime {runtime-version}: the TypeScript model, Maven coordinates `org.nasdanika.sdk.runtime.models.typescript:model:{runtime-version}`, namespace URI `{nsuri-ts}`; the React model, `{group-id}:{artifact-id}:{runtime-version}`, namespace URI `{nsuri}`; and the React Bootstrap and React Flow models, `{group-id}:bootstrap` and `{group-id}:flow`.
Every listing in it is included from the tests of those modules, which are compiled and run when the book is built, and every block of generated code is a file that a test compares with what the generator writes.
Its figure is a screenshot that a test took of a generated application in a browser.
