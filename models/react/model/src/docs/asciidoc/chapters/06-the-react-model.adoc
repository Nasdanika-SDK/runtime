== The React model

The TypeScript model leaves bodies as opaque code blocks, with no JSX, on purpose.
Generating React through it alone would put every component's body into opaque text and lose import management, provenance and structure.
`CodeBlock` has a `references` list so that a structured body could be substituted; the React model's `JsxBlock` is that substitution.

[cols="1,4",options="header"]
|===
| Area | Classes
| Base | `ReactElement`, `TsxModule`
| Components | `ComponentDeclaration`, a TypeScript function declaration; `JsxBlock`
| Hooks | `Hook`, `StateHook`, `EffectHook`, `MemoHook`, `ContextHook`, `RefHook`, `OpaqueHook`
| Context | `ContextDeclaration`, `ContextProvider`
| JSX | `JsxNode`, `JsxContainer`, `JsxElement`, `JsxFragment`, `JsxText`, `JsxExpression`, `JsxConditional`, `JsxIterator`, `OpaqueJsx`
| HTML | `Intrinsic`, an element of the HTML model used as a JSX intrinsic; `JsxContent`, JSX inside an HTML container
| Component libraries | `LibraryComponent`, `LibraryHook`, `ValueBlock`
| Attributes | `JsxAttribute`, `LiteralAttribute`, `ExpressionAttribute`, `EventAttribute`, `SpreadAttribute`
|===

`JsxElement.componentType` is the feature everything turns on: a reference to the component's declaration, which the generator follows to decide which components to import, from which module, and whether the import can be type-only.

=== HTML, shared

An `Intrinsic` holds an element of the HTML model, interpreted by the same structure the HTML generator uses.
A page model and a component model therefore mean the same markup, and HTML built by a transformation, a Bootstrap layout of the runtime's HTML Bootstrap model for example, can be used in a component as it is: `new ReactGenerator(new BootstrapStructure())` renders Bootstrap elements as intrinsics.

=== The generator

`ReactGenerator` is a TypeScript generator that also writes components with hooks, contexts and JSX.
The syntax is chosen per module: JSX in a `TsxModule`, written to `.tsx` and compiled with the automatic runtime, and `createElement` calls in any other module, which is plain JavaScript when it has no type annotations.
A component declared with `memo` is wrapped in React's `memo`; a component's documentation becomes JSDoc.
