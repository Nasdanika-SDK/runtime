== Building this book

This book is AsciiDoc in `models/jvm/model/src/docs/asciidoc`, built with the model after its tests have passed:

[source,text]
----
mvn -pl models/jvm/model -am verify                          # the model, its tests and this book
mvn -pl models/jvm/model verify -Dzephyr.editor-notes=false  # without editor's notes
mvn -pl models/jvm/model verify -Dasciidoctor.skip=true      # without the book
----

The PDF and the single-page HTML are written to `target/book` and attached to the model's artifact with the classifier `book`; the test sources are attached with the classifier `test-sources`.
The look comes from the runtime's `doc/zephyr` directory, shared by all the Nasdanika Zephyr Books.

Listings are tagged regions of the tests in `src/test/java/org/nasdanika/sdk/runtime/models/jvm/tests/book`, and of the module declaration.
A listing line holds at most 96 characters, and a warning fails the build.

The answer in <<a-snapshot>> is what `SnapshotTests` prints for the boot layer of the module's tests. A change to the module's dependencies changes it; run the tests and update the table.
