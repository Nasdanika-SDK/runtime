== Colophon

*Telemetry Model: A Nasdanika Zephyr Book*

Edition {revnumber}, built on {revdate}.

This edition describes the telemetry model of the Nasdanika SDK Runtime {runtime-version}, Maven coordinates `{group-id}:model:{runtime-version}`, namespace URI `{nsuri}` and the URIs of its `traces`, `logs` and `metrics` packages under it, and its exporters, `{group-id}:{artifact-id}:{runtime-version}`.
Every listing in it is included from the exporters' tests, which are compiled and run when the book is built.
