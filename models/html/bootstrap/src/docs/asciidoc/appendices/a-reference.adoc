=== Java classes

[cols="2,5",options="header"]
|===
| Class | What it is for
| `html.generator.Generator` | Writes a node as HTML. `setIndent(null)` writes on one line
| `html.generator.HtmlStructure` | Maps the HTML model to tags, attributes and children
| `bootstrap.generator.BootstrapStructure` | Maps the Bootstrap model, expanding components into HTML. `generate(node)` writes a node; `stylesheet(theme, ...)` and `javaScript(...)` give the URLs of the CDN
| `bootstrap.builders.NavigationTree` | Builds a navigation tree of `details` and `summary`
|===
