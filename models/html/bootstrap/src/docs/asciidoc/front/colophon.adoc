== Colophon

*HTML and Bootstrap Models: A Nasdanika Zephyr Book*

Edition {revnumber}, built on {revdate}.

This edition describes two models of the Nasdanika SDK Runtime {runtime-version}: the HTML model, Maven coordinates `{group-id}:model:{runtime-version}`, namespace URI `{nsuri-html}`, and the Bootstrap model, `{group-id}:{artifact-id}:{runtime-version}`, namespace URI `{nsuri}` and the URIs of its `forms` and `components` packages under it.
Every listing in it is included from the tests of the two modules, which are compiled and run when the book is built, and every block of generated HTML is a file that a test compares with what the generator writes.
