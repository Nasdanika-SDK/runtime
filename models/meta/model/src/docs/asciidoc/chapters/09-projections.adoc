[#projections]
== Projections

A vocabulary is worth writing down once because of what is projected from it.
The runtime has the first projection below, a glossary.
Its other projections are [.planned]#PLANNED#, and the tests of this book sketch one of them, to Ecore, to show the idea.

=== A glossary, for people

The first projection is for people: a glossary that cannot drift from the types, because both come from one source.

.A glossary (`MetaBookTests.java`)
[source,java]
----
include::{booktests}/MetaBookTests.java[tag=glossary,indent=0]
----
<1> One package, as Markdown.
<2> A glossary for each `.nmeta` file under a directory, read together as the validator reads them (<<validator>>), and returned as the list of files written. Validate first: a file with an error fails here.

A glossary is for people who do not read the notation, so `MetaGlossary` does not use it.
The Rule column states what the structure says, and the types are in plain words: a `string` is text, a `boolean` is yes or no, and a class from another package says so.

[cols="3,3",options="header"]
|===
| In the file | In the Rule column
| No multiplicity, `[1]`, `[*]`, `[+]` | optional, required, any number, at least one
| `[3]`, `[2..5]`, `[0..5]`, `[2..*]` | exactly 3, 2 to 5, up to 5, at least 2
| `id` | identifies it
| `contains` | part of it
| `opposite holders` on `Customer.accounts` | the other side of Account.holders
| `derived` | computed
| `readonly` | read-only
| `+= "fr"+` | fr by default
|===

Annotations and facets are left out.

<1> An instance of a class that has no Java class.
<2> The package is registered with the resource set, so its instances can be saved and loaded.

The identifying attribute becomes the instance's EMF ID, so references to a book in a file are by its ISBN.

The Ecore projection is the quiet one and possibly the most useful: a vocabulary captured in a spreadsheet can be validated, compared, diagrammed and serialized by tools that already exist.
It is also the conformance test of Meta, since a vocabulary projected to Ecore and back must come back the same, and the production path for models written in Meta that need Java.

=== What a projection decides

A projection decides what the neutral model leaves open:

* whether a `Class` becomes an interface, a type alias or a class;
* how a `DataType` is represented, from its `representation`;
* what to do with what the target cannot say: wildcards, unions in Java, operations in a data schema;
* which annotations it reads, by their source.

The model stays the same for every projection, which is what lets one vocabulary serve many.
