== Building this book

This book is AsciiDoc in `models/meta/model/src/docs/asciidoc`, built with the model after its tests have passed:

[source,text]
----
mvn -pl models/meta/model -am verify                          # the model, its tests and this book
mvn -pl models/meta/model verify -Dzephyr.editor-notes=false  # without editor's notes
mvn -pl models/meta/model verify -Dasciidoctor.skip=true      # without the book
----

The PDF and the single-page HTML are written to `target/book` and attached to the model's artifact with the classifier `book`; the test sources are attached with the classifier `test-sources`.
The look comes from the runtime's `doc/zephyr` directory, shared by all the Nasdanika Zephyr Books.

Listings are tagged regions of the tests in `src/test/java/org/nasdanika/sdk/runtime/models/meta/tests/book`, and of the module declaration.
A listing line holds at most 96 characters, and a warning fails the build.

The glossary in <<projections>> is `library.md` in `src/test/resources/org/nasdanika/sdk/runtime/models/meta/tests/book`, which `MetaBookTests` compares with what the projection writes. A change to the vocabulary or the projection changes it; run the tests, review the difference, and update the file.
