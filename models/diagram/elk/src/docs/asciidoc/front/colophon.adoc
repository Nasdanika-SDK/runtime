== Colophon

*Diagram Layout with ELK: A Nasdanika Zephyr Book*

Edition {revnumber}, built on {revdate}.

This edition describes the ELK module of the diagram model of the Nasdanika SDK Runtime {runtime-version}, Maven coordinates `{group-id}:{artifact-id}:{runtime-version}`, with the Eclipse Layout Kernel 0.12.0.
Every listing in it is included from the module's sources or tests, which are compiled and run when the book is built.
Its figures are diagrams generated and laid out by those tests, rendered with Draw.io's viewer into PNG images with the Draw.io document embedded.
