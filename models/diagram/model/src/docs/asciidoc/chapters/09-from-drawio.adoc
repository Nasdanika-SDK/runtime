== From Draw.io

Most diagrams start in an editor.
This chapter loads one from Draw.io: the figure of <<the-model>>, which is a PNG image with the diagram embedded.

The runtime's Draw.io module reads and writes Draw.io documents in Java, and its Zephyr Book, _Draw.io_, describes it.
Here it is only a source: a document of pages, layers, nodes and connections, with labels, tooltips and properties.

=== A converter

A loader for a notation maps its structure to the model's.
For Draw.io the mapping is close to one to one, and a minimal converter fits on two pages:

.A minimal converter from Draw.io to the diagram model (`DrawioToDiagram.java`)
[source,java]
----
include::{booktests}/DrawioToDiagram.java[tag=converter,indent=0]
----
<1> Every Draw.io page becomes a diagram inside the document's diagram, and every layer a layer.
<2> Connections are connected in a second pass, when every node has been converted, so a connection can point to a node that comes after it in the file.
<3> Draw.io lets connections leave from connection points on a node; `Util.getConnectableNode` returns the node either way.
<4> Draw.io nodes contain nodes and connections, and so do the model's.
<5> Labels in Draw.io are often HTML. The name keeps their text.

What the minimal converter leaves out, a complete one adds: Draw.io's connection points as ports, labels on connections as `Label` children, tags and styles as attributes, links between pages, and markers that record the file and page each element came from.
None of it needs a change to the model.
