== Colophon

*Diagram Model: A Nasdanika Zephyr Book*

Edition {revnumber}, built on {revdate}.

This edition describes the diagram model of the Nasdanika SDK Runtime {runtime-version}, Maven coordinates `{group-id}:{artifact-id}:{runtime-version}`, namespace URI `{nsuri}`.
Every listing in it is included from the module's tests or test resources, which are compiled and run when the book is built.
Its figure is a PNG image with a Draw.io diagram embedded, which the tests convert into the diagram model and check against the model it depicts.
