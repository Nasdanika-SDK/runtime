== Colophon

*Draw.io Model: A Nasdanika Zephyr Book*

Edition {revnumber}, built on {revdate}.

This edition describes the Draw.io model of the Nasdanika SDK Runtime {runtime-version}, Maven coordinates `{group-id}:{artifact-id}:{runtime-version}`, namespace URI `{nsuri}`.
Every listing in it is included from the module's tests or test resources, which are compiled and run when the book is built.
Its figure was generated by one of those tests, laid out with ELK and rendered by Draw.io's own viewer, and it is a PNG image with the Draw.io document embedded.
