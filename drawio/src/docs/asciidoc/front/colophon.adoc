== Colophon

*Draw.io: A Nasdanika Zephyr Book*

Edition {revnumber}, built on {revdate}.

This edition describes the `drawio` module of the Nasdanika SDK Runtime {runtime-version}, Maven coordinates `{group-id}:{artifact-id}:{runtime-version}`.
Every code listing in it is included from the module's tests, and every figure is a PNG image with its Draw.io diagram embedded, which those tests load.
When the book is built, the tests run first, so a listing in this book is code that compiled and passed against this version of the module, and a figure shows the very diagram its test read.
